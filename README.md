# Лексический анализатор для подмножества языка Pascal
## О программе
Лексический анализатор, предназначенный для обработки подмножества языка, схожего с Pascal. Анализатор выполняет лексический разбор входной строки, разделяя её на токены (лексемы), и выявляет лексические ошибки.

## Поддерживаемые конструкции
- Объявление переменных с типом record
- Вложенные записи
- Оператор case ... of с метками и полями
### Ключевые слова
```
service_words = ['var', 'case', 'end', 'of']
```
### Типы данных
```
types = ['integer', 'real', 'char', 'byte']
```
### Разделители
```
separators = [':', ';', ',', '(', ')']
```

## Примеры корректных выражений:
```
var a: record b: real; end;
var a: record case f of 1: (b: real;) 2: (ch: char;) 3: (bt: byte;) end; end;
var a: record case f of 1: b: real; 2: (ch: char;) end; end;
```

## Примеры лексических ошибок
```
var %a: record b: integer; end;    → Ошибка: символ '%' недопустим в идентификаторе
var 1a: record b: char; end;       → Ошибка: идентификатор начинается с цифры
```

## Примеры синтаксических ошибок
```
var a: case f of 1: d: integer; end;
```
